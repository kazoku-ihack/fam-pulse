Kazoku Pulse — Complete System Architecture

Apple Watch → iOS Parent app (elder, role parent) → Mendix Child app (caregiver, role adult_child) → Node/Express backend → Claude decision layer, Uber dispatch, caretaker email network, Protosure (activation + attestation), and the Avalanche Fuji on-chain JPYC payout path. Payout release to the insured's wallet fires only once a parametric trigger condition is validated (src/attestation-rules.js + src/coverage.js) and independently signed (offline stub or the real Protosure rater) — Claude never gates money.

Client apps API gateway / middleware Express routes Domain / business logic Claude decision layer Simulators External integrations Protosure Avalanche chain layer Data layer (SQLite)
